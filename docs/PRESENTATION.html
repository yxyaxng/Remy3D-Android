📷 采集端核心 1：Camera2 底层参数控制

Camera2 / ISP Control

多视点采集的光照与对焦一致性要求

在进行多视角 3D 重建时，若曝光值、白平衡和焦距随角度自动漂移，会导致反投影点云出现色差与伪影：

  • 自动曝光 (AE) 漂移：同一物体在不同角度因背景亮度变化产生明暗跳变；
  • 自动白平衡 (AWB) 漂移：不同视角照片出现色温偏差；
  • 焦点呼吸效应：自动对焦距离漂移导致视场角与背景特征混入。

NativeProCameraController 硬件级参数锁定

通过 Android Camera2 互操作层下发底层 ISP 请求：

val builder = CaptureRequestOptions.Builder()
builder.setCaptureRequestOption(CaptureRequest.SENSOR_SENSITIVITY, iso)
builder.setCaptureRequestOption(CaptureRequest.SENSOR_EXPOSURE_TIME, shutterNs)
builder.setCaptureRequestOption(CaptureRequest.LENS_FOCUS_DISTANCE, diopter)
builder.setCaptureRequestOption(CaptureRequest.CONTROL_AWB_MODE, AWB_MODE_LOCKED)
Camera2CameraControl.from(cameraControl).setCaptureRequestOptions(builder.build())

环绕拍摄全程保持曝光、色温与焦点锁定，保障多视点辐射一致性。

⚙️ 交互控制：提供手动拨盘调节 ISO（Auto/100~1600）、快门（1/30s~1/1000s）与微距对焦距离，并实时联动目标物距监测。

🌐 采集端核心 2：空间半球覆盖引导机制

Spatial Coverage Guide

多视角几何覆盖要求

立体匹配与三维点云闭合依赖充足的视角基线（Baseline）与半球覆盖：

  • 避免单一水平高度环绕：补齐物体顶部俯角与底部边缘视角，防止模型顶部与底座缺失；
  • 避免原地零基线重复拍摄：实时计算环形最短夹角，拦截同一角度重复快门。

36 单元立体穹顶网格设计 (Dome Grid)

结合机身 RotationVector 传感器 与竖屏坐标系重映射实时解析姿态角：

  • 垂直 3 层高度 (Pitch)：
    • 俯视角 [30°~75°]：采集顶部形态与特征
    • 平视角 [0°~30°]：采集主立面纹理
    • 仰视角 [-30°~0°]：采集底座与边缘
  • 水平 12 个扇区 (Yaw)：每 30° 划分一个观测区
  • 状态感知：总计 3 × 12 = 36 个空间网格单元，UI 实时展示同心环覆盖进度。
🔔 实时引导策略：当在已覆盖方位且角度差异 < 12° 时提示更换视角；当中层覆盖充足但顶层为空时，主动提示抬高手机补拍俯角。

🛡️ 采集端核心 3：毫秒级画质评估与实时主体追踪

Quality Gate & Target Lock

1. 离散拉普拉斯方差模糊检测 (< 5ms)

在后台协程对单次下采样位图执行批量像素数组读取与单趟拉普拉斯方差评估：

L(x, y) = |4*I(x, y) - I(x+1, y) - I(x-1, y) - I(x, y+1) - I(x, y-1)|
SharpnessScore = E[L^2] - (E[L])^2

若锐度得分低于阈值，弹出质量确认框供用户一键丢弃重拍，防止运动模糊图像混入重建队列。

2. 目标主体实时一致性追踪 (TargetTracker)

结合 CameraX ImageAnalysis 预览流与手动对焦刻度盘实时监测：

  • 首张合格照片提取中心区域 HSV 色相 (16-bin) 与饱和度 (8-bin) 直方图 作为基准指纹；
  • 预览期间每 180ms 实时计算直方图交集相似度与物距偏差；
  • 当镜头偏离目标时实时预警，移回目标或调回焦距后自动恢复正常锁定状态。
📐 数据源头质量控制：在采集阶段过滤模糊与偏离样本，保障后续几何反投影的输入质量。

🔍 特征采样算法：边缘轮廓与内部表面平衡

Feature Sampling

单一高梯度采样的局限性

若特征提取仅按 Sobel 梯度幅值从高到低截取前 $N$ 个点：

  • 现象：边缘轮廓线（强梯度）占满全部采样配额；
  • 问题：物体内部平滑区域（低梯度）被过滤丢弃；
  • 结果：生成的三维点云仅保留外框骨架，内部表面缺失。

分箱配额双轨特征采样实现

在 PhotoReconstructor.extractFeatures 中采用分箱配额：

// 提取高频 Sobel 边缘点与网格步长平滑采样点
val edgeFeatures = features.filter { it.strength > 0.35f }
val surfaceFeatures = features.filter { it.strength <= 0.35f }

// 刚性结构边缘配额：2,500 点
val selectedEdges = edgeFeatures.sortedByDescending { it.strength }.take(2500)
// 平滑实体表面填充配额：3,500 点 (均匀打散抽取)
val selectedSurfaces = surfaceFeatures.shuffled().take(6000 - selectedEdges.size)
return selectedEdges + selectedSurfaces
✨ 采样效果：以 2,500 个边缘点锁定物体几何边界，以 3,500 个内部采样点均匀填充实体表面色彩。

📐 几何反投影模型与外参推导

Back-Projection & Pinhole

1. 相机位姿与球面圆弧参数化

对于环绕物体拍摄的连续帧序列，按时序推算相机在空间圆弧上的相对位姿：

θi = -α/2 + (i / (N - 1)) * α
CamX = R * sin(θi), CamZ = R * cos(θi)
CamY = Y0 + ΔY * sin(t * π)

单体模式采用向心半径 $R=2.0\text{m}$；空间模式融合 ARCore 6-DoF 轨迹位移。

2. 针孔相机反投影到 3D 空间

将 2D 归一化图像特征坐标 $(u, v)$ 投影至世界坐标系射线：

focalLength = 1.0 / tan(FOV / 2)
dirX = (2u - 1) / focalLength
dirY = -(2v - 1) / focalLength, dirZ = 1.0

// 旋转矩阵转换至世界坐标
WorldDir = RotateY(θ) * Dir
Point3D = CamPos + WorldDir * EstimatedDepth

针对单体模式与大空间模式自适应约束景深范围与包围盒边界。

🧩 EXIF 方向校正：在特征提取前根据 ExifInterface.TAG_ORIENTATION 在内存中校正图像方向，确保反投影射线方向准确。

🧩 几何致密化引擎：SurfaceMesher

Surface Densification
为消除离散点云之间的空隙，工程通过 SurfaceMesher 实现端侧曲面拓扑连接与重心插值致密化。
1
空间体素降噪

体素尺寸 0.045m，计算体素内空间质心与平均颜色，滤除离群噪点。

2
极坐标空间参数化

以物体质心为原点，计算各点的球面极坐标 $(\phi, \theta)$ 并有序排列。

3
局部三角面片拓扑

邻近点间建立三角形拓扑，通过向量叉乘计算表面法向量 $\vec{N}$。

4
重心高斯细分填充

面片内部按重心坐标插值细分高斯基元，闭合表面孔隙。

✓ 性能表现：算法时间复杂度为 $O(N \log N)$，处理 15~30 张多视角特征点耗时小于 0.8 秒。

🎮 原生 OpenGL ES 2.0 着色器管线

Rendering Pipeline

1. 顶点着色器 (Vertex Shader)

将高斯椭球从 3D 世界空间变换至屏幕裁剪空间并展开 Billboard：

vec4 clip = uMVP * vec4(aCenter, 1.0);
float w = max(clip.w, 0.001);
vec2 offset = (aPos.x * aRx + aPos.y * aRy) * aSize * uBaseSize * w;
clip.xy += offset;
gl_Position = clip;

2. 片元着色器 (Fragment Shader)

实现高斯核指数衰减与屏幕 sRGB Gamma 校正：

float r2 = dot(vUV, vUV);
if (r2 > 1.0) discard;

float gaussian = exp(-2.2 * r2);
float gray = dot(vColor, vec3(0.299, 0.587, 0.114));
vec3 col = mix(vec3(gray), vColor, 1.28);
col = pow(clamp(col, 0.0, 1.0), vec3(1.0 / 1.85));
float finalAlpha = smoothstep(0.06, 0.92, clamp(vAlpha * gaussian, 0.0, 1.0));
gl_FragColor = vec4(col, finalAlpha);
⚡ 渲染交互控制：支持 “透视点云” 与 “高斯实体” 实时切换，支持 致密1x / 2x / 3x 动态调整椭球重叠半径，保持 60 FPS 渲染。
